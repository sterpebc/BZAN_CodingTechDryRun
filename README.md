# WELCOME!

You are in the Google-hosted coding environment that you will use during real exams. To make sure that everything is working as it should, please do the following steps:

1. On the Launcher tab, look for an icon labeled VS Code. Click it once.
2. Wait a bit. You should eventually see a user interface that looks like VS Code.
3. Look along the top edge of the window. You might see a message that says, "Restricted Mode is intended for safe code browsing" followed by some buttons. If you do see this, click the `Manage` button and on the window that pops up, click the `Trust` button to indicate that the folder you are working in is trustworthy. Then close the pop-up window by clicking the X in the upper right corner.
4. Create a new file. To do this, in the file navigator on the left side, click the icon that looks like a document with a + sign on it.
6. Notice that an empty line has opened up in the list of available files. This is where you type a name for the new file. Give it the name `test1.py` and hit Return.
7. Put some valid Python code in your new `test1.py` file. For example:

```
message = 'Hello, world'
print(message)
```

7. Run your code by clicking the Run triangle in the upper right of the window (where it usually is in VS Code).
8. If it runs correctly, you are finished. If anything went wrong, write down the details and email them to the instructor.
9. You can close the VS Code tab.
