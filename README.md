You are in the Google-hosted coding environment that you will use during real exams. To make sure that everything is working as it should, please do the following steps:

1. Look along the top edge of the window. You might see a message that says, "Restricted Mode is intended for safe code browsing" followed by some buttons. If you do see this, click the `Manage` button and on the window that pops up, click the `Trust` button to indicate that the folder you are working in is trustworthy. Then close the pop-up window by clicking the X in the upper right corner.
2. Create a new file in the BZAN_CodingTechDryRun folder. To do this, right click that folder in the file navigator along the left side and pick New File....
3. Notice that an empty line has opened up in the list of available files. This is where you type a name for the new file. Give it the name `test1.py` and hit Return.
4. Put some valid Python code in your new `test1.py` file. For example:

```
message = 'Hello, world'
print(message)
```

5. Run your code by clicking the Run triangle in the upper right of the window (where it usually is in VS Code).
6. If it runs correctly, you are finished. If anything went wrong, write down the details and email them to the instructor.
7. You can close the VS Code tab.
